Manifolds
=========

The hyperbolic spaces themselves, and the exact maps between their charts.
Curvature is fixed to ``k = 1`` throughout; a metric scale is applied in the
loss, not here.

-----------

The lossless canonical chart ``(r, v)``, plus the warped-metric manifold that
carries H^{D+1}'s true geodesic-polar geometry.
