# Hub-dominated graphs of small diameter

The two negative controls of the curvature experiments: graphs whose nodes are spread
over a narrow range of radii, where the closed-form Hydra initialization already leaves
little for any optimizer to improve.

Each file is a whitespace-separated edge list on integer labels `0..N-1`. Both are
vendored rather than regenerated on use so that a number is checkable against a fixed
graph, and both can be regenerated byte-identically with the commands below.

| File | Nodes | Edges | Diameter |
|---|---|---|---|
| `powerlaw200.edgelist` | 200 | 780 | 4 |
| `airports_europe.edgelist` | 399 | 5993 | 5 |

## Provenance

**`powerlaw200.edgelist`** — a Holme–Kim graph (Holme & Kim, *Growing scale-free
networks with tunable clustering*, Phys. Rev. E 65, 026107, 2002): preferential
attachment with `m = 4` edges per new node, plus a triad-formation step taken with
probability `p = 0.5`. Generated with NetworkX 3.4.2:

```python
import networkx as nx
nx.write_edgelist(nx.powerlaw_cluster_graph(200, 4, 0.5, seed=0),
                  "powerlaw200.edgelist", data=False)
```

**`airports_europe.edgelist`** — the European air-traffic network of struc2vec (Ribeiro,
Saverese & Figueiredo, KDD 2017, Sec. 4.4: commercial flights from Eurostat, January to
November 2016, 399 airports and 5995 edges), loaded through PyTorch Geometric. Its two
self-loops are removed, which leaves 5993 edges:

```python
import networkx as nx
from experiments.datasets import airports_graph
G, _ = airports_graph("Europe")
nx.write_edgelist(G, "airports_europe.edgelist", data=False)
```
